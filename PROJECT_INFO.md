# EncargosYa Cuba - Información del Proyecto

## 📋 Nombres Únicos del Proyecto

Para evitar conflictos con otros proyectos similares, este proyecto usa nombres únicos:

### 🎯 Identificadores del Proyecto:
- **Nombre del Proyecto:** `EncargosYa Cuba`
- **Frontend:** `encargosya-cuba-frontend`
- **Backend:** `encargosya-cuba-backend`
- **Base de Datos:** `encargosya_cuba_db`
- **Puerto Backend:** `3002`
- **Puerto Frontend:** `3000`

### 🇨🇺 Características Específicas de Cuba:
- **Moneda:** Pesos Cubanos (CUP)
- **Formato de números:** `es-CU`
- **Tasa de cambio por defecto:** 420 CUP por USD
- **Mercado objetivo:** Cuba

### 📁 Estructura de Carpetas:
```
encargosya-cuba/
├── frontend/ (Next.js)
├── backend/ (NestJS)
├── database/ (PostgreSQL)
└── docs/
```

### 🔧 Configuración de Base de Datos:
- **Nombre:** `encargosya_cuba_db`
- **Puerto:** `5432`
- **Usuario:** `postgres`
- **Esquema:** Optimizado para el mercado cubano

### 🌐 URLs del Proyecto:
- **Frontend:** http://localhost:3000
- **Backend API:** http://localhost:3002/api
- **Base de Datos:** localhost:5432

### 🚀 Comandos de Inicio:
```bash
# Frontend
npm run dev

# Backend
cd backend
npm run start:dev
```
